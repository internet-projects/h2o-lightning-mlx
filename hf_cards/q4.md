# H2O-Lightning-4B — MLX 4-bit

A 4-bit MLX conversion (affine, group size 64; mlx-vlm 0.7.8) of [h2oai/h2o-lightning-4b](https://huggingface.co/h2oai/h2o-lightning-4b) **v1.3.1**, for Apple Silicon. 3.0 GB. The smallest build, for one-way reading.

Published by [NetProjects](https://netprojects.com) (Internet Projects Ltd). Not affiliated with H2O.ai.

This is a **decision model**, not a chat model. It returns a probability for each answer option, not text.

> **Serve it with the H2O shim, not with `mlx_lm.server` or a plain `mlx_vlm` generate call.** The generic "Use this model" snippets Hugging Face shows for MLX models do not return the label probabilities this model is made for. The commands below set it up with H2O's official shim, unmodified, on top of [h2o-lightning-mlx](https://github.com/internet-projects/h2o-lightning-mlx), which reads the label log-probabilities with a float32 head, as the original does on vLLM.

| JevBench public (231, JevBench v1.2.1, `--adapter typesafe`), one-way | |
|---|---|
| this checkpoint | **199 / 231** (48/48 · 70/72 · 81/111) |
| original weights on MLX (bf16) | 198 / 231 |
| H2O's model card (vLLM) | 198 / 231 |
| vs bf16 on MLX | 221 / 231 answers identical; probability drift mean 0.023, p95 0.106 |

**Which build?** This build serves one-way reading: start it with `TWO_WAY=0`. For H2O's two-way reading (203 / 231), and for the closest match to the original's calibration, use the [8-bit build](https://huggingface.co/netprojects/h2o-lightning-4b-mlx-q8) (5.1 GB).

**Images.** Image input works through the unchanged shim. On H2O's own receipt example this build picks the same answer as the original weights, with somewhat lower confidence (0.88 against 0.98). It is not a reproduction of H2O's image benchmark.

**Limits** (as for the original): mostly evaluated in English; works best with about 16 answer options or fewer; no explanations and no video input.

```bash
git clone https://github.com/internet-projects/h2o-lightning-mlx && cd h2o-lightning-mlx && ./setup.sh
hf download netprojects/h2o-lightning-4b-mlx-q4 --local-dir mlx-q4
TWO_WAY=0 MODEL=mlx-q4 ./serve.sh # http://127.0.0.1:8741/v1/systemone
```

**Versions.** `main` is H2O v1.3.1 (updated 19 October 2026). The previous build, H2O v1.2.3 (207 / 231), stays available with `hf download netprojects/h2o-lightning-4b-mlx-q4 --revision v1.2.3`; use it with `git checkout v1.2.3` in the GitHub repo.
