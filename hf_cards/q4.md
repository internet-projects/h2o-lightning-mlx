# H2O-Lightning-4B — MLX 4-bit

A 4-bit MLX conversion (affine, group size 64; mlx-vlm 0.7.8) of [h2oai/h2o-lightning-4b](https://huggingface.co/h2oai/h2o-lightning-4b) **v1.4.1** (commit `cc18ee330e6895c41b9a60f37a0dd122dc4c3461`), for Apple Silicon. 2.9 GB. The smallest build, for one-way reading. Box questions work.

Published by [NetProjects](https://netprojects.com) (Internet Projects Ltd). Not affiliated with H2O.ai.

This is a **decision model**, not a chat model. It returns a probability for each answer option (or, for a Box question, a bounding box), not free text.

> **Serve it with the H2O shim, not with `mlx_lm.server` or a plain `mlx_vlm` generate call.** The generic "Use this model" snippets Hugging Face shows for MLX models do not return the label probabilities this model is made for. The commands below set it up with H2O's official shim, unmodified, on top of [h2o-lightning-mlx](https://github.com/internet-projects/h2o-lightning-mlx), which reads the label log-probabilities with a float32 head, as the original does on vLLM.

**Which build?** This build serves one-way reading: start it with `TWO_WAY=0`. For H2O's two-way reading (205 / 231; H2O's own result 206) and for the closest match to the original's calibration, use the [8-bit build](https://huggingface.co/netprojects/h2o-lightning-4b-mlx-q8) (4.8 GB).

**Box questions** (always on since v1.4.0) work on this build too: on H2O's receipt example it finds the total-amount line with confidence 0.90 (8-bit: 0.97).

**Speed** (MacBook Pro M5 Max, 27 October 2026, through `serve.sh`, one request at a time): about 59 ms per JevBench item, a 2,000-token record in 0.36 s, a 32K-token state in 7.4 s. MLX peak memory 5.7 GB at 4K tokens and 6.8 GB at 32K.

**Images.** Image input works through the unchanged shim. On H2O's own receipt example this build gives the same answers as the original weights. It is not a reproduction of H2O's image benchmark.

**About v1.4.1** (from H2O's card): the v1.4.0 fine-tune continued on more training data, with unchanged calibration constants; stronger on retrieval and on six task families the added data covers, level on H2O's held-out decision skills overall. This build ships the training tokenizer (`tokenizer/`), which the shim checks at start.

**Limits** (as for the original): mostly evaluated in English; works best with about 16 answer options or fewer; no explanations and no video input.

```bash
git clone https://github.com/internet-projects/h2o-lightning-mlx && cd h2o-lightning-mlx && ./setup.sh
hf download netprojects/h2o-lightning-4b-mlx-q4 --local-dir mlx-q4
TWO_WAY=0 MODEL=mlx-q4 ./serve.sh # http://127.0.0.1:8741/v1/systemone
```

**Versions.** `main` is H2O v1.4.1 (27 October 2026: rebuilt from v1.4.1, new upstream weights). Earlier builds stay available: H2O v1.4.0 (one-way, 202 / 231) with `--revision v1.4.0`, H2O v1.3.1 (one-way, 199 / 231) with `--revision v1.3.1`, and H2O v1.2.3 (207 / 231) with `--revision v1.2.3`; use each with the matching tag in the GitHub repo.
