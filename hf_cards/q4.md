# H2O-Lightning-4B — MLX 4-bit

A 4-bit MLX conversion (affine, group size 64; mlx-vlm 0.7.8) of [h2oai/h2o-lightning-4b](https://huggingface.co/h2oai/h2o-lightning-4b) **v1.4.0**, for Apple Silicon. 2.9 GB. The smallest build, for one-way reading. Box questions work.

Published by [NetProjects](https://netprojects.com) (Internet Projects Ltd). Not affiliated with H2O.ai.

This is a **decision model**, not a chat model. It returns a probability for each answer option (or, for a Box question, a bounding box), not free text.

> **Serve it with the H2O shim, not with `mlx_lm.server` or a plain `mlx_vlm` generate call.** The generic "Use this model" snippets Hugging Face shows for MLX models do not return the label probabilities this model is made for. The commands below set it up with H2O's official shim, unmodified, on top of [h2o-lightning-mlx](https://github.com/internet-projects/h2o-lightning-mlx), which reads the label log-probabilities with a float32 head, as the original does on vLLM.

| JevBench public (231, JevBench v1.2.1, `--adapter typesafe`), one-way | |
|---|---|
| this checkpoint | **202 / 231** (48/48 · 71/72 · 83/111) |
| original weights on MLX (bf16) | 203 / 231 |
| vs bf16 on MLX | 222 / 231 answers identical; probability drift mean 0.039, p95 0.165 |

**Which build?** This build serves one-way reading: start it with `TWO_WAY=0`. For H2O's two-way reading (206 / 231, the same as H2O's own result) and for the closest match to the original's calibration, use the [8-bit build](https://huggingface.co/netprojects/h2o-lightning-4b-mlx-q8) (4.8 GB).

**Box questions** (always on since v1.4.0) work on this build too: on H2O's receipt example it finds the total-amount line with confidence 0.85 (8-bit: 0.96).

**Images.** Image input works through the unchanged shim. On H2O's own receipt example this build gives the same answers as the original weights. It is not a reproduction of H2O's image benchmark.

**About v1.4.0** (from H2O's card): a new fine-tune with images in its training data, stronger than v1.3.2 on H2O's held-out decision skills, and weaker on retrieval (product-search relevance) and on choosing a function to call.

**Limits** (as for the original): mostly evaluated in English; works best with about 16 answer options or fewer; no explanations and no video input.

```bash
git clone https://github.com/internet-projects/h2o-lightning-mlx && cd h2o-lightning-mlx && ./setup.sh
hf download netprojects/h2o-lightning-4b-mlx-q4 --local-dir mlx-q4
TWO_WAY=0 MODEL=mlx-q4 ./serve.sh # http://127.0.0.1:8741/v1/systemone
```

**Versions.** `main` is H2O v1.4.0 (updated 25 October 2026). Earlier builds stay available: H2O v1.3.1 (one-way, 199 / 231) with `--revision v1.3.1`, and H2O v1.2.3 (207 / 231) with `--revision v1.2.3`; use each with the matching tag in the GitHub repo.
